## iPhone 使用同一 LAN 審查

1. 電腦與 iPhone 連到同一個私人 Wi‑Fi，使用這輪提供的電腦私有 IPv4 預覽網址，用 Safari 開啟，不用先安裝，也不要輸入個人持股。
2. 依序檢查今日重點、核心卡分數與回落、雙圖拖曳／輕點、切換標的／閱讀模式後返回、事件與 00631L、自選。請把截圖或操作問題記下。
3. 若無法連線，檢查是否同子網、Wi‑Fi 是否隔離各設備，或 Windows 防火牆是否阻擋。此驗收不要求更改防火牆／路由器或使用公開通道。
4. LAN 的 HTTP 網址是不同來源，**不能**證明 Secure Context 的 Service Worker、主畫面 PWA 更新／持久重啟、推播或僅正式來源可用的 00631L 自動啟動。

WebKit 回歸兩個跳過：原生離線導覽在最小測試站也會出現 WebKit 內部錯誤；Windows WebKit 的持久化設定檔在空白測試站就無法保證跨完整關閉重啟保留 localStorage。隔離分頁關閉／重開及 Chromium 對照仍運行；最後須用 iPhone Safari 安全來源與已安裝圖示補驗兩項，不可用 LAN HTTP 代替。
