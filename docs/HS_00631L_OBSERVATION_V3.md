# 00631L 急跌機會雷達 V3

本功能僅描述已完成的收盤交易日，不使用 C4、交易授權或金融儲存。
舊 Shadow 的排程、EOD 連動和 push 觸發在候選變更中退場；
保留人工工作及全部研究封存。未發現 B2 定時工作。

## 資料與發布閘門

- 已有日線依原封存 SHA 驗證；2026-03-31 之前的高低收盤已按 22:1
  換算。後續原始 OHLC 不重複調整。
- STOCK_DAY 增量須搭配同期間 FMTQIK 交易日、TWT49U 公司行動與
  TWTCAU 分割檢查；接點或已發布日有修訂、來源不存在或方案未核准就不覆蓋。
- [TWSE 網站使用條款](https://www.twse.com.tw/zh/terms/use.html)第六、
  八項不將網站查詢介面開放給一般自動擷取及公開再利用。
  [開放資料集 11549](https://data.gov.tw/dataset/11549)每日更新，但
  [平台歷史查詢說明](https://data.gov.tw/suggests/136936)指出現有公開
  資料集不能當作可指定歷史日期的日線 API。不要套用錯誤的授權範圍。
- 自動收集閘門 **預設關閉**。只有端點的自動擷取與公開衍生快照都已核准，
  或改為獲授權的等價流程，才能啟用。隔離驗證快照不納入公開提交。
- 最小替代路徑：用現有免費 OpenAPI 每日盤後存證；從有可追溯來源的
  歷史檔補齊封存後的缺日，另外驗證公司行動的期間涵蓋與分割口徑。
  在尚未補齊前，不可將兩日間的跨缺口報酬當成固定五個交易日。

## 顯示口徑

門檻為 2014 年起的封存日線至 2020-12-31 所得固定 P80/P95，
下跌幅度以百分點表示。在不足指定窗口長度時不納入門檻訓練。
統計自 2021 年開始，每類只收首次跨極端門檻、彼此至少相隔 21 個
交易日的事件。5/10/20 日必須成熟，最大不利變動為觸發收盤至
後續最低價；不含股息再投入、不含交易成本，不能解讀為可成交獲利。
不足十件隱藏正報酬比例；長期高點回落不是互相獨立的每日事件。
