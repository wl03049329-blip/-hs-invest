# V3.2.0 最後七項阻塞修復

## 009815：真正缺漏，不是測試特例

既有發布目錄只有TWSE267筆、TPEx0筆。來源紀錄指出TPEx ISIN TLS逾時，
但原匯入器僅以全市場筆數>=100判斷不需備援，錯將單一市場缺漏發布。
本輪由原官方TWSE基金與兩市場ISIN網址重新取得原始回應，保存時間、URL、
SHA與原始內容；原解析器可解析TPEx119筆，含009815（2026-01-26掛牌）。
目錄新增119筆、不刪除既有267筆、不改其欄位。搜尋與精選採用同一可追溯目錄；
個人持股的名稱目錄原已有009815。目錄不等於可用行情、native證據或C4啟用資格。
WAIT_NATIVE與全部C4公式、風控、交易Writer維持原狀。

匯入器現在要求兩市場ISIN成功且非空，缺市場即失敗、保留舊檔；既有代號
若消失也須人工核對，不能靜默刪除。未來匯入亦保存來源SHA、時間及HTTP狀態。
完整官方回應與本機對照證據保留在工作區外，不把測試輸出當來源。

原核心計算及portfolio-v6.js/CSS仍實測目前保留的模組；已退休DOM僅與明確標示的

不配置、投入不超現金、不可變輸入，以及Writer OFF。再驗證新部位可只設35%、
