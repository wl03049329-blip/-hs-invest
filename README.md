HS | ETF股市雷達 v6.2

## v6.2 介面與首頁

v6.2 使用黑色／石墨灰科技風主題與 HS＋雷達＋K 棒品牌圖示，提供 SVG favicon、Apple Touch Icon、192／512px PWA 圖示及 `site.webmanifest`。手機版使用五格固定底部導覽；桌面版保留六個含圖示的頂部分頁。

首頁首屏將台股加權、上櫃、台積電、黃金、布蘭特原油、情緒與精選 ETF 買點濃縮呈現。「今天怎麼買」只做客觀條件彙整，不使用必買、抄底或保證語句。

黃金與布蘭特原油改用 Twelve Data Commodity API 的結構化一分鐘資料（`XAU/USD`／`XBR/USD`）。API Key 只存放於 GitHub Secret `TWELVE_DATA_API_KEY` 或自有授權 Proxy，不會寫入公開前端；未設定授權來源、資料過舊或抓取失敗時保留最後成功值並明確標示，絕不以 0 代替。

## 市場脈動動態行情

前端只有一個行情輪詢控制器：現貨交易時段約每 20 秒檢查、商品約每 45 秒，頁面進入背景會取消計時器與尚未完成的請求，回到前景立即更新。所有行情快取請求皆使用 `cache: "no-store"` 與時間戳，並以來源時間判斷更新中、延遲、過期或正式收盤；沒有 Service Worker cache-first。

公開 GitHub Pages 預設以 GitHub Actions 產生的官方結構化快取作為初始值與失敗 fallback。若要取得 15～30 秒的盤中行情或台指期日／夜盤，需在「更多」設定自有 HTTPS 授權行情 Proxy，金鑰必須留在伺服器端。台指期未設定授權來源時只顯示臺灣期貨交易所最近官方收盤，並清楚提示盤中行情需授權來源，不會將每日行情冒充為目前夜盤價。

## 台股融資風險

首頁與籌碼頁會讀取 `margin-data.json`，同時呈現融資餘額、20／60 日位置及市場融資維持率。融資餘額以臺灣證券交易所、櫃買中心公開結構化資料為基礎，歷史序列由 FinMind API 彙整；平日台北時間 18:00 更新、19:00 補抓。

目前交易所公開的是個別信用帳戶維持率公式，未提供同口徑的全市場平均維持率序列，因此該欄位明確顯示「資料暫時無法取得」，不以 0%、個人帳戶數字或自行推估值替代。未來只有在取得合法、同口徑且可驗證的結構化來源後才會納入市場恐慌因子，且影響上限為 15%，不會直接改變波段進場條件。

## 股票型 ETF 買點模型

新版綜合買點固定權重：技術低檔 20%、估值吸引力 15%、止跌確認 25%、中長期趨勢 15%、歷史相似訊號 15%、市場情緒 5%、流動性與資料品質 5%。缺少資料不會當成 0 分；可用權重達 70% 才會把剩餘項目重新正規化。

盤後正式分數使用完整收盤 OHLCV。盤中試算使用同源快取的免費延遲行情建立暫定 K 棒；若只有最新價，成交量與當日高低點相關條件會沿用盤後正式資料並顯示覆蓋率。

00830 的估值優先使用 Invesco 公開 JSON 中 SOXQ 的基金估值。SOXQ 與 00830 同樣追蹤 PHLX Semiconductor Sector Index；SOXX 追蹤 NYSE Semiconductor Index，只列為次級產業代理。估值歷史不足 30 筆時不顯示歷史百分位。

## 持有策略模式

- 長期核心：高點回檔 25%、估值吸引力 20%、技術低檔 15%、市場恐慌 15%、長期趨勢與基本面 10%、歷史相似訊號 10%、止跌確認 5%。
- 波段操作：止跌確認 30%、趨勢轉強 25%、技術低檔 15%、動能改善 10%、歷史相似訊號 10%、估值背景 5%、市場環境與流動性 5%。

弘昇精選的 0050、00830、00662、009815 使用長期核心模式；00935、00631L、00733、006201 使用波段模式。使用者自選的策略選擇只寫入自己的瀏覽器 `localStorage`。

估值快取涵蓋 0050 官方持股加權估值、00830 的 SOXQ／SOXX、00662 的 QQQ／QQQM、009815 的 QQQM／QQQ，以及 00935 的官方 benchmark 背景。沒有同口徑資料時保留缺值，不以 0 分代替。

「更多」頁的高點回檔價位工具使用還原分割後歷史行情，提供 52 週高點、歷史最高點與自訂高點的 -5% 至 -70% 價位；盤中延遲價只更新目前回檔級距，不覆蓋正式高點。
