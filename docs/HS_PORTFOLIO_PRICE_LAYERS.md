# 持股估值、價格變動及帳本損益

- 資產估值：使用已核驗的收盤價與有效股數；總資產另外需要有效現金。完整組合未核實時，只顯示同一資料日已核實的小計，不顯示重算的占比。
- 價格變動估算：以目前股數及兩個已核驗交易日的同口徑收盤價計算。不含交易、配息、費用，也不使用該金額填入帳本。
- 帳本當日損益：只顯示原有帳本驗證器已獨立核實的金額，不變更契約。

## 官方開放行情的比較基準

[TWSE 11549](https://data.gov.tw/dataset/11549) 與 [TPEx 11371](https://data.gov.tw/dataset/11371) 是兩個免費開放資料集，授權不外推至其他歷史查詢。11/24 官方開放列核對八檔收盤價。相對 11/23 兩市開放收盤快照，八檔當日漲跌欄位皆可數值對帳；這不是對所有交易狀態的保證。

11/24 的除息對照列：TWSE 00901、00930 的有成交列給出數字 `0.0000`，TPEx 00958B、00990B 給出文字「除息」。因此「數值存在，甚至等於零」不能證明前收可比。依 [TWSE 交易制度](https://www.twse.com.tw/zh/products/system/trading.html) 與 [TPEx FAQ 10–11](https://www.tpex.org.tw/zh-tw/about/company/faq.html)，初次交易、除權息、前一日無成交及恢復交易都可能採不同參考價。分割、反分割、減資如改變股價或持股單位，必須取得相應證據，不能從一個數字推斷。兩張普遍行情表沒有足夠的獨立證據區分上述各種情況。

所以本次只獨立發布顯示調整，不採用「收盤減漲跌」的新估算路徑。006201、00631L、00685L 仍需逐日可驗證的比較基準與單位證據；估值不等待這些證據。
