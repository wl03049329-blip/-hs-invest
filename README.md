# HS ETF 股市雷達 2.0

HS ETF 股市雷達是以 GitHub Pages 發布的靜態投資資訊工具，整合 ETF 長期核心分數、波段／槓桿專用引擎、市場情緒、籌碼與僅儲存在瀏覽器的個人持股。

## 2.0 正式核心模型

長期核心主分數使用 `FINAL_CORE_WEIGHT_V1`：

- 週 J 低檔：30%
- 52 週高點回檔：55%
- 20 日急跌：15%

三個核心因子任一缺失即不評分（`FAIL_CLOSED`），不以其他因子補權重。週乖離、市場恐慌與估值只作輔助資訊，不參與正式核心分數、排名、標籤、歷史觸發率或 CTA。0050、00662、00830、00935 已有 canonical 校準；009815 在核心因子歷史不足時安全顯示 N/A。

畫面分數向下取整，門檻判斷使用未取整的精確分數。歷史觸發率是校準樣本中該區間的出現頻率，不是未來報酬或勝率。

## 資料與更新

盤中快照時段為台北交易日 09:30、10:30、11:30、12:30、13:30。Weekly J、52 週回檔、20 日急跌與 Core Score 使用最新成功 `marketAsOf`；更新失敗時保留上一筆成功資料，不以瀏覽器現在時間冒充資料時間。盤後正式資料與盤中快照各自保留其正確語意。

市場行情、融資、法人、期貨籌碼、CNN Fear & Greed 與估值資料各自標示來源日期。缺值不以 0、NaN 或 Infinity 代替。公開站不含私人 API Key；需要授權來源時，金鑰只應放在 GitHub Secrets 或自有後端代理。

## 策略與隱私

0050、00662、00830、00935、009815 顯示長期核心資訊；00631L、00733、006201 維持既有槓桿／波段專用引擎、Gate、Stage 與 Exit Pressure。緊急 rollback 路徑保留，但 production 預設固定為 `FINAL_CORE_WEIGHT_V1`。

自選、持股、交易狀態與設定只儲存在使用者目前瀏覽器的 `localStorage`，不會上傳至 GitHub 或伺服器。

所有分數、歷史驗證、行情與籌碼僅供資訊整理，不構成投資建議，也不保證報酬或最低點。
